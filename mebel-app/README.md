# Рукша Мебель · Заказы (мини-апп)

Отдельное приложение для учёта заказов мебели. Не связано с базой «Фитнес Фракции».

## Статус

Каркас: палитра шалфея, доска «Заказы» с колонкой на каждый этап (замер → монтаж), пустые состояния, тесты палитры и этапов.
Данных пока нет: колонки пустые, выдуманных заказов нет.
Ещё не сделано: вход через Telegram initData, база Neon, роли, экраны этапов и задач, напоминания.

## Запуск

```
cd mebel-app
npm install
npm test
npm run build
npm run dev
```

## Дизайн

Палитра «шалфей» взята из состояния fraktsiya `67d4d7f`. Значения лежат в `src/styles/tokens.css`,
тест `src/tokens.test.ts` не даёт поменять их случайно.

## Вне этого шага

Бот (`bot/` или корень ветки `feat/ruksha-mebel-bot`) остаётся для уведомлений. Токен бота только в переменных окружения.
